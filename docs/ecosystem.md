# Ecological scope reviewed 2026-10-21

The original FindCore indexes documents and ranks query results. MoonRetrieve already exposes SearchIndex, BM25/ranked retrieval, phrase/Boolean queries, indexing and snapshot/load APIs: https://mooncakes.io/docs/niuniu513-ask/MoonRetrieve . These are substantive overlaps. The current replacement is ProtocolDiff, not another retrieval variant; original FindCore remains a historical library, with no claim the overlap was eliminated by renamed APIs.

TraceLens byte-capture recovery is compared with existing durable-log software, including moonbitstack/moonraft (https://github.com/moonbitstack/moonraft). Both use durable log/replay concepts. TraceLens does not implement consensus: its specific checked responsibilities are physical UTF-8/CRLF boundaries, captured byte ranges, source rotation and deterministic analysis replay. SHA-256, filesystem sync and generic journaling are not claimed as novel inventions.

ProtocolDiff accepts explicit deterministic partial Mealy models and compares their observable behavior, builds shortest differences, minimizes and audits reset-based transition suites. Rz-coder8848/moon-fsm is an existing FSM execution/transition-validation package (https://mooncakes.io/docs/Rz-coder8848/moon-fsm); reachability and state-machine concepts overlap. ProtocolDiff's claimed deliverable is cross-version behavioral comparison and verifiable output traces, rather than a generic FSM runtime or unique invention of automata methods. It does not support arbitrary guards, arbitrary side effects, timed/nondeterministic or inferred network protocols.

Shared JSON Value/CLI helpers across the October repositories are disclosed separately from domain code. Review included public original repositories, published module APIs, targeted ecosystem searches and normalized exact-file comparison across local TraceLens, FindCore, ProtocolDiff and HistoryCheck production sources. This does not prove absence of all overlapping software, legal originality or competition eligibility. Organizer evaluation is still required. No third-party automata or retrieval domain source is imported into the replacement by this review.
