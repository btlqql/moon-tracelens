# Follow-up 0.3.0 / registry 0.3.0

Date: 2026-10-18.

## Implemented revision

新增 buckets 操作，按 width_seconds 和 origin 划分左闭右开的时间桶；负时间与小数边界同样按 floor 定义处理。每桶复用事件数、错误数、错误比例和延迟 p95，保留摄入诊断，空桶省略。先应用现有过滤，再生成桶；输出事件总数可以与桶计数之和对照。

## Scope

不填补空时间桶、不进行观察时长归一化，不把桶统计解释为因果关系或统计显著性。离线内存分析不包含实时 tail 和轮转恢复。

## Verification

The existing fixture ladder remains in CI. New assertions are in tests/cases.json and independent oracles run through the real compiled CLI via scripts/followup_reference.py. Tests use synthetic deterministic inputs. Claims of release validation are recorded only after the relevant CI and independent installation checks finish.
